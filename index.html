( 02 )

PawnLogic

FLAGSHIP — ACTIVE

A terminal-first autonomous AI agent. Multi-provider model routing, persistent memory, real tool execution, MCP integration — published on PyPI, versioned, and CI-tested.

  • A

    Multi-provider routing

    DeepSeek · OpenAI · Anthropic, with per-call reasoning-effort budgets from off to max.

  • B

    Persistent memory

    Recoverable sessions and durable context for long, multi-turn technical work.

  • C

    Sandboxed execution

    Agent-generated commands are isolated in Docker before they ever touch the host.

  • D

    MCP & CTF toolchain

    MCP integration plus opt-in extras — pwntools, ROPgadget, ropper — as installable skill packs.
